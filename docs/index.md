# U02-E01-mmorcid0203

## Descripción del proyecto

Este proyecto sirve para practicar el usp de Git y GitHub y aprender
a gestionar las versiones de un proyecto web.

## Estructura del proyecto

- index.html: página principal.
- estilos.css: hoja de estilos.
- scrpt.js: archivo JavaScript. 
- docs/index.md: documentación del proyecto.

## Herramientas utilizadas

- Git: control de versiones.
- MkDocs: generación de documentación.
- Markdown: estructura de documentación.
